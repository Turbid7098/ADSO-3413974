# ¿Qué es un SRS?

**SRS** (Especificación de Requisitos de Software) es un documento formal que detalla **qué** debe hacer un sistema de software, sin explicar **cómo** implementarlo.

## Propósito clave
- Consolida recolección/análisis de requisitos (funcionales, no func., negocio).
- Guía desarrollo: prioriza features, casos de uso, evita malentendidos.
- Base para pruebas y validación en proyectos como SENA.[file:1]

**Ejemplo**: En SRS Supermercado La Esquina, lista RF-01 (ventas), matriz priorización y CU-01 (registrar venta).[file:1]
